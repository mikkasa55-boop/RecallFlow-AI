## Overview
**RecallFlow AI** is an interactive browser-based active recall and study management assistant built to help students convert passive lecture notes into structured question-and-answer flashcards, extract core concepts, and stay focused with an integrated Pomodoro timer.

## Key Features
- **Instant Active Recall Deck:** Automatically turns pasted notes and definitions into interactive hide/reveal flashcards.
- **Key Concept Extraction:** Identifies and highlights key technical terms from the study material.
- **Smart Pomodoro Focus Timer:** Includes a 25-minute Deep Focus mode, 5-minute Short Break mode, and live study progress counters.
- **Zero-Setup Execution:** Runs natively in any modern web browser using HTML5, CSS3, and Vanilla JavaScript.

## How to Run
1. Open the live GitHub Pages deployment link or download `index.html` and open it directly in any browser.
2. Paste your study notes (or click **Load Sample CS Notes**) and click **Generate Active Recall Deck**.
